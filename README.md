# cc_report_analyzer
App de análisis de reportes de tarjetas de crédito

Esta es una herramienta de análisis de reportes de gastos de tarjetas de crédito.

El script lee un pdf que contiene el reporte enviado por un banco comercial con la información de gastos y pagos de un cliente para un período determinado.

El código del script está escrito en el lenguaje python y hace uso de los siguientes paquetes:

- pandas
- matplotlib
- sqlite
- entre otras librerías.
